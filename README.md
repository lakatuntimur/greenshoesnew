# GREENROOM — Telegram Mini App

Готовая серверная основа магазина: каталог, поиск, фильтры по бренду, размеру, категории и диапазону цен; карточки товара; корзина; заказы; связь с менеджером; защищённое управление товарами и загрузка фото. Интерфейс на русском, адаптирован к Telegram на телефоне.

## Что опубликовано

Ссылка Sites — **закрытый демонстрационный интерфейс**, доступный владельцу. Там нет Node.js API и общей базы, заказы отключены. Демонстрационные изменения администратора остаются только в браузере. Для покупателей Telegram нужно разместить **серверную версию** ниже на общедоступном HTTPS-домене. Не используйте закрытую ссылку Sites как URL рабочего бота.

При первом запуске новой базы демонстрационный каталог отключён — реальные товары добавляет администратор.

См. [пошаговую инструкцию для Render](DEPLOY-RENDER.md). В комплект включён `render.yaml` с постоянным диском и настройками магазина.

## Запуск сервера

Нужен Node.js 24+, внешние npm-зависимости отсутствуют.

```sh
cp .env.example .env
npm start
```

Локальный адрес: http://localhost:3000. Настройте `.env` только на сервере:

- `BOT_TOKEN` — токен вашего бота из @BotFather, только секрет сервера.
- `ADMIN_TELEGRAM_IDS` — числовые Telegram ID администраторов, через запятую.
- `MANAGER_USERNAME` — username менеджера без @. Он должен принимать сообщения покупателей.
- `PUBLIC_ORIGIN` — общедоступный HTTPS-домен магазина без пути, например `https://shop.example.com`.
- `DEMO_CATALOG=false` — пустой каталог при **первом** запуске новой базы. Демонстрационные товары уже созданной базы удаляются через админку; демонстрационные товары заказать нельзя даже после настройки бота.
- `DATA_DIR` — необязательный путь к постоянному каталогу данных, по умолчанию `.data/`.

Без заполненных настроек оформление заказа отключено. Товары и заказы хранятся в SQLite, фотографии загружаются как данные товара. Не удаляйте каталог данных при обновлении. Размещайте одну серверную реплику с постоянным диском, настройте резервное копирование SQLite через SQLite backup API или при остановленном сервере. База содержит контакты покупателей; доступ к диску должен быть ограничен.

## Размещение и подключение Telegram

1. Запустите сервер на VPS или платформе с Node.js 24 и постоянным диском. Перед ним настройте HTTPS reverse proxy, передающий запросы на порт 3000.
2. Можно собрать `Dockerfile` и запустить контейнер с env-файлом и постоянным томом `/app/.data`, доступным пользователю node (UID 1000). Образ использует непривилегированного пользователя.
3. Заполните переменные выше. Перезапустите сервер.
4. Установите кнопку меню бота:

```sh
node --env-file=.env scripts/connect-bot.mjs
```

Скрипт проверяет бота и вызывает Telegram `setChatMenuButton`. Токен не выводит. При необходимости это можно сделать вручную: @BotFather → `/mybots` → выбрать бота → Bot Settings → Menu Button → Configure menu button → публичный HTTPS URL → «Открыть магазин».

5. Для кнопки запуска в профиле бота настройте Main Mini App в @BotFather для того же URL.
6. Откройте **через меню бота**. Администратор с указанным Telegram ID увидит шестерёнку управления, сможет удалить демотовары и добавить реальные товары.
7. Проверьте тестовый заказ вторым Telegram-аккаунтом: товар пропадает при нулевом остатке, заказ виден покупателю и администратору, кнопка связи открывает менеджера с текстом заказа.

Подпись Telegram `initData` проверяется сервером HMAC-SHA256; `initDataUnsafe` не используется для прав доступа. Сеанс действует 1 час; после истечения нужно открыть миниапп заново. Вне Telegram можно только просматривать каталог. Нельзя назначить себя администратором переключателем в интерфейсе.

## Заказы

При оформлении сервер проверяет доступность каждого товара и сам рассчитывает цену. В одной транзакции сохраняет заказ и уменьшает остатки. Заказ резервирует вещь сразу. Оплату и доставку покупатель согласует с менеджером; онлайн-эквайринг не подключён. Возврат резерва после отмены, статусы исполнения и уведомления менеджеру ботом не реализованы: администратор может вручную изменить остаток. Кнопка связи открывает чат; сообщение отправляет сам покупатель.

Демонстрационные фото с Unsplash и шрифт Manrope с Google Fonts включены в локальные файлы. Для запуска замените фото на свои и при необходимости разместите шрифты локально. Один товар содержит одно фото; лимит загрузки 1 МБ. Для большого каталога рекомендуется вынести изображения в объектное хранилище.
