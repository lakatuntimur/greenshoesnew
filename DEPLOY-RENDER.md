# Размещение GreenShoes на Render

Сервер в комплекте, покупать отдельный домен не обязательно: Render выдаёт публичный HTTPS-адрес. Для SQLite выбран **платный сервис с постоянным диском 1 ГБ**. Стоимость проверьте на экране Render до создания ресурсов. В этом сеансе ресурсы и аккаунты не созданы, расходы не оформлены.

## 1. Подготовьте аккаунты и код

1. Создайте аккаунт на https://github.com и приватный репозиторий, например `greenshoes-shop`.
2. Скачайте и распакуйте архив `greenroom-telegram-shop.zip`.
3. В репозитории выберите **Add file → Upload files** и загрузите содержимое распакованной папки. В корне должны лежать `server.mjs`, `package.json`, `render.yaml` и папка `public`. Сохраните изменения (**Commit changes**).
4. Не загружайте `.env`, базу `.data/` или токен бота. В архиве секретов нет.

## 2. Запустите сервис

1. Зарегистрируйтесь на https://render.com через GitHub.
2. Выберите **New → Blueprint**, подключите созданный репозиторий. Разрешите Render доступ именно к нему.
3. Render прочитает `render.yaml`. Проверьте план и стоимость сервиса и диска.
4. В поле секрета **BOT_TOKEN** вставьте новый токен @GreenShoes_Bot. Предыдущий токен, опубликованный в переписке, сначала отзовите через @BotFather → `/revoke`. Новый не отправляйте в чат и не добавляйте в GitHub.
5. Создайте ресурсы и дождитесь успешного запуска. Если платформа предлагает другой план или версию Node, сохраните Node 24+ и постоянный диск. Бесплатный сервис без диска не подходит для этой SQLite-базы.
6. Откройте выданный адрес `https://….onrender.com`. Скопируйте его. Домен приложение берёт из `RENDER_EXTERNAL_URL`, заполнять `PUBLIC_ORIGIN` вручную не нужно. Для своего домена задайте `PUBLIC_ORIGIN` отдельно.

Настройки бота, менеджера и администратора уже заполнены. База на `/var/data` переживает перезапуски и обновления, пока вы не удалите диск. Резервные копии базы нужно настроить отдельно.

## 3. Подключите меню Telegram

Вариант без командной строки:

1. Откройте @BotFather → `/mybots` → @GreenShoes_Bot.
2. Откройте **Bot Settings → Menu Button → Configure menu button**.
3. Введите выданный Render HTTPS-адрес, затем подпись **Открыть магазин**.
4. Для кнопки в профиле настройте **Main Mini App** для того же адреса, если этот пункт доступен в текущем меню BotFather.
5. Откройте чат @GreenShoes_Bot и нажмите **Открыть магазин**.

Если используете Render Shell, можно выполнить `node scripts/connect-bot.mjs`: команда проверит username бота и настроит кнопку автоматически. Секрет она берёт из окружения Render, вводить его в команде не нужно.

## 4. Первая проверка

- Откройте магазин в Telegram с аккаунта `1649889192`. Нажмите шестерёнку, добавьте реальную вещь с фотографией, ценой, размером и остатком.
- Со второго аккаунта проверьте поиск, фильтры, карточку и заказ. Реальный заказ резервирует остаток; после проверки верните тестовый остаток вручную.
- В заказе откройте связь с @GreenBarigaManager и самостоятельно отправьте подготовленное сообщение.
- Бот не рассылает уведомления автоматически. Администратор видит заказы внутри магазина. Оплата и доставка согласуются с менеджером.

Если запуск не удался, пришлите текст ошибки из Render Logs, предварительно скрыв секреты и контакты покупателей. Поле BOT_TOKEN и полный env-файл не пересылайте.
